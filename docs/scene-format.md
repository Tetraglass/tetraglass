# Scene format (draft, version 1)

Status: **draft**. Implemented in M1 (task M1.1); filters are added in M2 and M4. The JSON Schema generated by `tetraglass schema` is authoritative once it exists; this file explains it and must be kept in sync (`.agents/rules/scene-schema.md`).

## Top level

```json
{
  "version": 1,
  "sources": { "<name>": { ... } },
  "filters": { "<name>": { "type": "...", "input": "<name>", ... } },
  "view": { "show": [ ... ], "camera": { ... }, "lights": "default", "background": "white" },
  "output": { "image": "out.png", "size": [1200, 800] }
}
```

| Key | Required | Meaning |
| --- | --- | --- |
| `version` | yes | Schema version. Breaking changes bump it and ship a migration. |
| `sources` | yes | Named datasets read from files. |
| `filters` | no | Named derived datasets. Each takes `input`, the name of a source or another filter. Cycles are errors. |
| `view` | yes | What is shown and from where. |
| `output` | only for `render` | Image settings for headless rendering. |

Names are lowercase `snake_case`, unique across sources and filters. Unknown keys are errors everywhere.

## Sources

```json
"flow": { "file": "results.pvd" }
```

| Field | Default | Meaning |
| --- | --- | --- |
| `file` | required | Path relative to the scene file. Format from the extension: `.vtu`, `.vtk`, `.pvd`, `.msh`. |
| `format` | from extension | Override, for example `"vtu"`. |
| `linearize_level` | `2` | Subdivision level for higher-order cells (M2). |

## Filters

Every filter has `type` and `input`. Arrays on the input are carried to the output and interpolated where geometry is cut.

```json
"hull": { "type": "surface", "input": "flow" },
"cut": { "type": "slice", "input": "flow", "origin": [1.0, 0.5, 0.5], "normal": [1.0, 0.0, 0.0] },
"iso": { "type": "contour", "input": "flow", "field": "velocity:magnitude", "values": [0.5, 1.0, 1.5] },
"half": { "type": "clip", "input": "flow", "origin": [1.0, 0.5, 0.5], "normal": [1.0, 0.0, 0.0], "keep": "back", "mode": "exact" }
```

| `type` | Milestone | Fields |
| --- | --- | --- |
| `surface` | M1 | none: the external surface (also implied when a volume mesh is shown directly) |
| `slice` | M2 | `origin` (default: center of bounds), `normal` (required, non-zero) |
| `contour` | M2 | `field` (array reference, scalar or component), `values` (list of numbers) |
| `clip` | M2 | `origin`, `normal`, `keep` (`"front"` default or `"back"`), `mode` (`"exact"` default or `"crinkle"`) |
| `threshold` | M2 | `field`, `min`, `max` (either may be omitted for one-sided) |
| `streamlines` | M4 | `vectors`, `seeds` (`{"point": [...]}`, `{"line": {"from": [...], "to": [...], "count": n}}` or `{"plane": {...}}`), `max_length`, `direction` (`"forward"`, `"backward"`, `"both"`) |
| `glyphs` | M4 | `vectors`, `shape` (`"arrow"`, `"cone"`, `"sphere"`), `scale_by` (`"magnitude"` or a number), `every` (stride) |
| `resample` | M4 | `dimensions` ([nx, ny, nz]); output used by the `volume` representation |

## Array references

A string `"<array>"` or `"<array>:<component>"`.

- Components of vectors: `x`, `y`, `z`, `magnitude`. Tensors: `xx`, `xy`, ... and `magnitude`. Any array: a zero-based index such as `velocity:0`.
- If the name exists as both point and cell array, point data wins; force with `"point:<array>"` or `"cell:<array>"`.
- Unknown names are validation errors with a suggestion.

## View

### `show`: list of representations

```json
{ "input": "cut", "style": "surface", "color_by": "velocity:magnitude", "colormap": "viridis", "range": "auto", "colorbar": true }
```

| Field | Default | Meaning |
| --- | --- | --- |
| `input` | required | Source or filter name. |
| `style` | `"surface"` | `"surface"`, `"surface_with_edges"`, `"wireframe"`, `"points"`; `"lines"` and `"tubes"` for streamlines; `"volume"` for resampled data (M4). |
| `color_by` | none | Array reference. Without it, `color` is used. |
| `color` | `"lightgray"` | Solid color: a CSS name or `[r, g, b]` in 0 to 1. |
| `colormap` | `"viridis"` | `"viridis"`, `"cividis"`, `"cool_warm"`, `"turbo"`, `"grayscale"`. |
| `range` | `"auto"` | `"auto"` (current time step), `"auto_all_steps"`, or `[min, max]`. |
| `log_scale` | `false` | Logarithmic color mapping; values must be positive. |
| `center` | none | For diverging colormaps: value mapped to the middle of the map. |
| `opacity` | `1.0` | 0 to 1. Below 1 uses order-independent transparency (M3). |
| `colorbar` | `false` | `true`, or `{ "title": "...", "position": "right" }`. |
| `edge_color` | `"black"` | For `surface_with_edges` and `wireframe`. |
| `point_size` | `3.0` | Pixels, for `"points"`. |
| `visible` | `true` | Keep a representation in the file but hide it. |

### `camera`

```json
{ "fit": "all", "azimuth": 30, "elevation": 20, "zoom": 1.0, "projection": "perspective" }
```

| Field | Default | Meaning |
| --- | --- | --- |
| `fit` | `"all"` | `"all"` or a source/filter name to frame. Ignored when `position` is given. |
| `azimuth`, `elevation`, `roll` | `0`, `0`, `0` | Degrees, applied after fitting, around the focal point. |
| `zoom` | `1.0` | Greater than 1 moves closer. |
| `position`, `focal_point`, `view_up` | none | Explicit camera; overrides `fit`, angles and zoom. |
| `projection` | `"perspective"` | Or `"orthographic"`. |
| `view_angle` | `30` | Degrees, perspective only. |

### Other view fields

| Field | Default | Meaning |
| --- | --- | --- |
| `lights` | `"default"` | `"default"` (headlight plus key and fill) or `"headlight"`. |
| `background` | `"white"` | Color, or `{ "top": ..., "bottom": ... }` gradient. |
| `axes` | `true` | Show the axes triad. |
| `title` | none | Text drawn at the top of the image. |

## Output

```json
{ "image": "out.png", "size": [1600, 900], "time": "last" }
```

| Field | Default | Meaning |
| --- | --- | --- |
| `image` | required | PNG path relative to the scene file; the CLI's `-o` overrides it. |
| `size` | `[1200, 800]` | Pixels. |
| `time` | `"first"` | `"first"`, `"last"`, a time value, or `{ "step": n }`. |
| `frames` | none | Animation (M4): `{ "from": ..., "to": ..., "pattern": "frame_%04d.png" }`. |
| `msaa` | `4` | Sample count; fixed in gallery scenes. |
| `engine` | `"raster"` | `"raster"` or `"cycles"` (M3); the CLI's `--engine` overrides it. |
| `cycles` | none | `{ "samples": 128, "device": "auto", "save_blend": "scene.blend" }` (M3). |

## Validation messages

Every error names the JSON path and, where possible, a fix:

```
view.show[0].color_by: no array "presure" on "flow"; did you mean "pressure"?
filters.cut.normal: must not be [0, 0, 0]
filters.iso.input: unknown dataset "flw"; defined are "flow", "cut"
```
